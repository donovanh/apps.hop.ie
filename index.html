hop.ie API

Pay-per-call AI services via Lightning Network micropayments.

Buy credits once with Bitcoin Lightning. Use them across all services. No subscription, no sign-up required — just an API key.

How it works

  1. Buy credits — POST to /api/v1/credits, pay the Lightning invoice, receive your API key
  2. Call services — include Authorization: Bearer <apiKey> on every request
  3. Credits deducted automatically — each call costs a small number of credits
  4. Check balance — every successful response includes X-Credits-Remaining: <n> so you always know how many credits you have left

Quick start

# 1. Buy credits — returns a Lightning invoice and your accountId
curl -X POST https://api.hop.ie/api/v1/credits \
  -H "Content-Type: application/json" \
  -d '{"quantity": 100}'

# 2. Pay the invoice with any Lightning wallet, then verify:
curl -X POST https://api.hop.ie/api/v1/credits/verify \
  -H "Content-Type: application/json" \
  -d '{"invoiceId": "<id>", "quantity": 100}'
# → { "apiKey": "sk_...", "accountId": "...", "credits": 100, "balance": { ... } }

# 3. Use a service with your API key
curl -X POST https://api.hop.ie/email-validator/validate \
  -H "Authorization: Bearer <apiKey>" \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com", "tier": "basic"}'
