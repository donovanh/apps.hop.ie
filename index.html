Lightning Tools

Pay-per-call tools for AI agents, powered by Bitcoin Lightning.

Buy credits once. Spend them on tool calls. No subscriptions, no sign-up required — just an API key.

How it works

  1. Buy credits — POST to /api/v1/credits, pay the Lightning invoice, receive your API key
  2. Call any tool — include Authorization: Bearer <apiKey> on every request
  3. Balance tracked automatically — every response includes X-Credits-Remaining so your agent always knows where it stands

Quick start

# 1. Buy credits — returns a Lightning invoice and your API key
curl -X POST https://api.hop.ie/api/v1/credits \
  -H "Content-Type: application/json" \
  -d '{"quantity": 100}'

# 2. Pay the Lightning invoice, then verify:
curl -X POST https://api.hop.ie/api/v1/credits/verify \
  -H "Content-Type: application/json" \
  -d '{"invoiceId": "<id>", "quantity": 100}'
# → { "apiKey": "sk_...", "credits": 100 }

# 3. Call a tool
curl -X POST https://api.hop.ie/email-validator/validate \
  -H "Authorization: Bearer <apiKey>" \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com", "tier": "basic"}'
