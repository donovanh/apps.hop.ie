Calculator

Deterministic arithmetic, scientific, geometric, trigonometric, and conversion calculations. Always correct — no tokens wasted reasoning through maths.

⚡ 1 credit per call

API Reference

Endpoint

POST https://api.hop.ie/calculator/calculate

Required headers

Authorization: Bearer <apiKey>
Content-Type: application/json

Example request

{
  "operation": "evaluate",
  "params": { "expression": "2 * (3 + 4) ^ 2" }
}

Example response

{
  "operation": "evaluate",
  "result": 98
}

Why use this

LLMs burn tokens reasoning through maths and still produce wrong answers. One API call costs 1 credit and is always deterministic. Use it for anything numeric — from basic arithmetic to quadratic roots, trig ratios, volume calculations, and unit conversions.

Pricing

Any operation 1 credit

Request format

{
  "operation": "<operation-name>",
  "params": { "<field>": "<value>" }
}

All errors return a 200 with an error field (the call was valid and is still charged). Unknown operations or missing fields return a 400 with no charge.

Error responses

Math errors (division by zero, no real roots, etc.) return 200 with an error field — the call consumed 1 credit.

{ "operation": "divide", "error": "Division by zero" }

Unknown operation or missing field returns 400 — no credit charge.
